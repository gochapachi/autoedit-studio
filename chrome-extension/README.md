# AutoEdit Studio — Chrome Extension Floating Teleprompter

This is a companion Manifest V3 Chrome Extension that displays a floating, auto-scrolling teleprompter overlay over any browser tab, Google Slides presentation, Loom recording, or desktop demo.

## How to Install in Google Chrome:

1. Open **Google Chrome** and navigate to `chrome://extensions/`
2. Enable **Developer mode** toggle in the top-right corner.
3. Click **Load unpacked** in the top-left corner.
4. Select the directory: `E:\Anagata Video Editor for founders\chrome-extension`
5. The **AutoEdit Studio Teleprompter** icon will appear in your Chrome toolbar!

## Features:
- **Floating & Draggable**: Drag the header to position the prompter anywhere on your screen.
- **Auto-Scroll with Spacebar**: Press <kbd>Space</kbd> to toggle play/pause smoothly.
- **Speed & Font Sliders**: Fine-tune scroll speed and text size in real time.
- **Transparent Backdrop**: Stays legible without blocking your presentation slides or code editors.
